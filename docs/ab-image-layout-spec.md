# playready A/B 문서 이미지 배치 규칙 명세

이 문서는 `playready`가 자동 생성하는 두 문서의 시각 자료 배치 원칙을 정리한 기준 문서입니다.

- 문서 A: 혼자 공부할 때 보는 상세 학습 자료
- 문서 B: 다른 플레이어에게 설명할 때 보여주는 설명 보조 자료

이 명세의 목적은 "이미지가 붙는다" 수준이 아니라, "문서 목적에 맞게 읽기 쉬운 시각 자료가 붙는다" 수준으로 품질을 맞추는 것입니다.

## 1. 공통 원칙

### 1-1. 이미지 선택 원칙
- PDF에서 추출된 원본 이미지를 그대로 다 쓰지 않습니다.
- 이미지가 붙는 기준은 `nearestTextBlockId`와 해당 텍스트 블록의 문맥입니다.
- 아래 종류로 분류한 뒤, 문서 목적에 맞는 것만 사용합니다.
  - 구성물 이미지
  - 세팅 이미지
  - 아이콘 이미지
  - 보드 이미지
  - 장식성 이미지 또는 사용 가치가 낮은 이미지

### 1-2. 품질 원칙
- 여백이 과도한 이미지는 가능한 한 잘라서 사용합니다.
- 아이콘은 일반 이미지와 같은 크기로 넣지 않고, 작은 참조 카드 형태로 묶습니다.
- 캡션은 PDF 추출 원문을 거의 그대로 붙이지 않고, 짧고 읽기 쉬운 요약으로 만듭니다.
- 깨진 문자, 특수 공백, private-use 문자 등은 캡션 생성 전에 제거합니다.

### 1-3. 문서 흐름 원칙
- 이미지는 문서의 읽는 흐름을 방해하지 않게 배치합니다.
- 텍스트를 대신하는 이미지가 아니라, 텍스트를 빠르게 이해하게 도와주는 이미지여야 합니다.
- 이미지가 많아도 한 번에 길게 늘어놓지 않고, 목적별 섹션으로 나눕니다.

### 1-4. 액션 흐름 도식화 원칙
- 문서 A와 문서 B 모두 "내 턴에 무엇을 할 수 있는지"를 도식화한 섹션을 반드시 포함합니다.
- 도식화는 화려한 그래픽보다 이해가 쉬운 순서형 카드 레이아웃을 우선합니다.
- 예시 흐름:
  - 시작 단계 -> 선택 단계 -> 실행 단계 -> 정리 단계
  - A -> B/C 택1 -> D -> 종료
- 도식화에는 아래 정보가 들어가야 합니다.
  - 턴 시작 시 확인할 것
  - 선택 가능한 대표 액션
  - 액션 이후 이어지는 결과
  - 턴 종료 또는 정리 단계

## 2. 문서 A 배치 규칙

문서 A는 학습용이므로 "자세한 이해"가 우선입니다.

### 2-1. 구성물 섹션
- 제목 예시: `주요 구성물 이미지`
- 목적:
  - 공용 구성물과 개인 구성물을 구분해서 이해하게 돕기
- 배치:
  - 2열 카드형 이미지
  - 캡션은 짧게 `공용 구성물`, `개인 보드 예시`, `연료 토큰 예시`처럼 표시

### 2-2. 세팅 섹션
- 제목 예시: `세팅 참고 이미지`
- 목적:
  - 공용 준비와 개인 준비를 실제 배치 예시로 보여주기
- 배치:
  - 큰 보드/세팅 이미지 우선
  - 텍스트와 붙여 읽기 쉬운 위치에 삽입

### 2-3. 아이콘 섹션
- 제목 예시: `주요 아이콘 참조표`
- 목적:
  - 자주 등장하는 아이콘을 빠르게 익히게 돕기
- 배치:
  - 작은 아이콘 전용 그리드
  - 큰 사진 카드처럼 보이지 않도록 작은 카드나 표 형태 사용
  - 캡션은 `연료 획득`, `건설 비용`, `연구 전진`처럼 짧은 의미 중심

### 2-4. 보드 섹션
- 제목 예시: `개인 보드/공용 보드 예시`
- 목적:
  - 보드 구조를 미리 파악하게 돕기
- 배치:
  - 전체 보드가 잘 보이는 이미지를 소수만 선택
  - 보드 주변 설명과 연결되도록 배치

### 2-5. 액션 흐름 도식화
- 제목 예시: `턴 진행 흐름 한눈에 보기`
- 위치:
  - 턴 순서 또는 핵심 메커니즘 섹션 근처
- 표현:
  - 직선형 또는 분기형 흐름 카드
  - 예: `턴 시작 -> 행동 선택 -> 결과 처리 -> 종료 정리`

## 3. 문서 B 배치 규칙

문서 B는 설명용이므로 "짧고 빠른 전달"이 우선입니다.

### 3-1. 세팅 개요 이미지
- 제목 예시: `게임 준비 한눈에 보기`
- 목적:
  - 설명 시작 전에 플레이어가 전체 판을 한 번에 이해하게 돕기
- 배치:
  - 큰 개요 이미지 1~2장 우선
  - 너무 많은 갤러리 대신 핵심만

### 3-2. 구성물 요약 이미지
- 제목 예시: `공용/개인 구성물 요약`
- 목적:
  - "이건 모두가 같이 쓰고, 이건 개인이 쓰는 것"을 빠르게 보여주기
- 배치:
  - 공용 / 개인 구분이 되도록 카드 그룹화

### 3-3. 아이콘 요약 카드
- 제목 예시: `중요 아이콘 빠른 참조`
- 목적:
  - 설명 중 자주 헷갈리는 아이콘만 빠르게 보여주기
- 배치:
  - 작은 아이콘 카드 4~8개
  - 설명용 문장보다 한 줄 설명 우선

### 3-4. 보드 예시
- 제목 예시: `보드 보는 법`
- 목적:
  - 개인 보드와 공용 보드를 설명할 때 빠르게 참조
- 배치:
  - 큰 전체 보드 1장, 필요 시 보조 이미지 1장 정도

### 3-5. 액션 흐름 도식화
- 제목 예시: `내 턴에는 이렇게 진행합니다`
- 위치:
  - 소개 스크립트 또는 첫 라운드 가이드 앞
- 표현:
  - 설명자가 옆에서 보여주기 쉬운 간단한 흐름도
  - 복잡한 규칙보다 "이번 턴에 뭘 하면 되는지" 중심

## 4. 이미지 선별 규칙

### 4-1. 우선 사용 이미지
- 텍스트 블록과 가까운 구성물 이미지
- 세팅 설명 근처의 보드/배치 이미지
- 아이콘 설명 근처의 작은 심볼 이미지
- 개인 보드, 공용 보드 전체 구조가 보이는 이미지

### 4-2. 제외 또는 우선순위 낮춤
- 장식용 일러스트
- 여백이 너무 큰 이미지
- 너무 작아서 내용 식별이 어려운 이미지
- 같은 의미의 중복 이미지
- 문맥 연결이 약한 이미지

## 5. 캡션 규칙

- 캡션은 원문 복사 대신 요약형으로 씁니다.
- 기본 형식:
  - `룰북 4페이지 | 공용 구성물 예시`
  - `FAQ 1페이지 | 정오표 반영 아이콘`
- 길이는 짧게 유지합니다.
- 깨진 문자나 특수 기호는 제거합니다.

## 6. 인쇄용 스타일 규칙

- A4 기준으로 잘리지 않게 구성합니다.
- 이미지 카드, 표, 흐름도는 페이지 중간에서 찢기지 않게 합니다.
- 제목 직후 바로 페이지가 넘어가지 않게 합니다.
- 아이콘 표는 너무 크지 않게 압축합니다.
- 액션 흐름 도식화는 인쇄 시에도 좌우 정렬이 무너지지 않도록 카드형 블록을 씁니다.

## 7. 구현 기준 요약

구현은 아래 순서로 적용합니다.

1. PDF 추출 단계에서 텍스트와 이미지 정제
2. 이미지 분류 메타데이터 생성
3. 문서 A/B 목적에 따라 다른 자동 이미지 섹션 구성
4. 문서 A/B 공통 액션 흐름 도식화 섹션 생성 또는 보강
5. 다운로드 HTML에 인쇄 최적화 스타일 적용
